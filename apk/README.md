# apk/

Put the official **TikTok 47.1.3** APK here as:

```
TikTok-47.1.3.apk
```

foxi installs it during first-time setup. It checks the file byte for byte, so it has to be this exact file.

- Source: [APKMirror: TikTok 47.1.3](https://www.apkmirror.com/apk/tiktok-pte-ltd/tik-tok-including-musical-ly/tiktok-47-1-3-release/tiktok-47-1-3-android-apk-download/) (choose the **APK**, not the bundle)
- SHA-256: `8b5569f592a5534652ae460ef1d9e7f7394b5b7fdde44ae64f106d76767e2622`
- Signed by TikTok's key: certificate SHA-256 `9041803e91bcb814b4b4399fb5c85a91640b755e5e8ba76813814bf4cf2ab5ba`

APK files in this folder are ignored by git: TikTok's app isn't redistributed in the repository.
